# AutoClick Pro Max

Windows 10/11 auto-clicker with draggable numbered target circles.

## Download EXE

Open GitHub Actions > Build AutoClick Windows EXE > latest successful run > Artifacts > AutoClickProMax-Windows-EXE. Unzip and run AutoClickProMax.exe.

## Controls

Drag numbered circles to target positions. Set interval in milliseconds and mouse button. Press F6 to start/stop. Save/load click positions in JSON. Move the mouse to the upper-left corner for PyAutoGUI emergency failsafe.
